# Поиск фильмов

Простое веб-приложение для быстрого поиска фильмов напрямую через API.

Проект сделан как альтернативный способ поиска фильмов без необходимости заходить в основной MovieGrisha.

## Стек

* JavaScript / TypeScript
* React
* Vite
* REST API

## Возможности

* Поиск фильмов
* Получение данных через API
* Быстрый просмотр результатов поиска

## Статус

Готовый небольшой вспомогательный проект.
